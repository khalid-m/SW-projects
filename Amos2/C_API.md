# Public C API (`C/*.h`)

Every declaration exported by the headers in [AmosNT_floq/C/](AmosNT_floq/C/), the API for C programs that
embed Amos II (*callin*) or implement AmosQL functions in C (*callout*). Generated by
[tools/gen_c_api.py](tools/gen_c_api.py). Do not edit by hand; rerun the script.
How the API is used: [KERNEL.md §6–7](KERNEL.md#6-the-c--lisp-bridge); examples in
[C/](AmosNT_floq/C/) (`amosdemo.c`, `callout.cpp`) and [demo/](AmosNT_floq/demo/).

- **325** declarations in **10** headers (284 functions). `jni.h`/`jni_md.h` (Java's own headers) are skipped.
- **Implemented in**: for functions, where the body is. **118** are defined in `system/C` source (linked). **159** exist only in a binary object in `system/MVC/` (named by module, from `nm`; see [KERNEL.md §2](KERNEL.md#2-what-has-source-and-what-doesnt)). Blank means neither was found: a macro, a function defined elsewhere (e.g. JavaAmos), or one missing from this checkout.
- **Section** is the nearest preceding `/*** … ***/` heading in the header.
- **Comment** is the header's own comment for that declaration.
