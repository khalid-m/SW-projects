# AmosQL system functions

The AmosQL functions that the standard image defines: what a user can call. Generated by
[tools/gen_amosql_functions.py](tools/gen_amosql_functions.py). Do not edit by hand; rerun the script.

- **690** definitions (533 distinct names; overloaded names have several rows) in **51** files.
- Covers `lsp/` files in image load order and the `.osql`/`.amosql` files they load, plus the MEXIMA,
  AQIT, BigIntegrator and wrapper files that `init.lsp` loads. Other subsystems (SCSQ, SciSPARQL, …)
  define many more functions and are not covered.
- Four definition forms are parsed: AmosQL `create function` statements (in AmosQL files or in
  `(osql "…")` strings inside Lisp), `(foreign-lispfn …)` and Lisp `(create-function …)`.
- **Implementation**: `stored` (a relation, [STORAGE.md §3](STORAGE.md#3-stored-functions-and-their-relations)),
  `derived` (a query), `procedure`, `multidirectional`, or `foreign` with the implementing Lisp or C
  function. For foreign names, look them up in [LSP_FUNCTION_INDEX.md](LSP_FUNCTION_INDEX.md) or
  [C_BUILTINS.md](C_BUILTINS.md).
- **Comment** is the `/* … */` comment of the definition, or a `foreign-lispfn` docstring.
  Signatures are shown as parsed; Lisp-form types are capitalized for readability.
