Running RDQLFront
-----------------

RDQLFront lets you execute RDQL query strings through Amos II. It uses
HP's Jena 2 package. Described in
http://user.it.uu.se/~udbl/Theses/JosefSchindlerMSc.pdf. 
See demo.amosql for examples.

1. Download Jena 2 from 
    http://jena.sourceforge.net/downloads.html

2. Set environment variable JENA_HOME to point to Jena 2 root
   directory, e.g.
    C:\Program\Jena-2.1

3. Run RDQLfront with
    RDQLFront.cmd

   Try command
    < 'demo.amosql';
