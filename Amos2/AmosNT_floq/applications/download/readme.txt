Generic file downlod system (currently zips only).

The file downloads.amosql contains basic schema definitions.

The file systems.amosql contains examples of definitions of systems to
download, named 'sward' and 'amos'.

1. Load both files into the database image used by Apache/PHP.

2. Place the PHP files in the htdocs subfolder into your htdocs
directory of Apache.

To download a system called X use the URL dl.php?what=X
