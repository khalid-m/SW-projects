Project Notes

Project: JavaAMOS
Author: Kristofer Cassel, Daniel Elin
Company: EDSLAB - Linköping University
Description:
Compiles all Java code in JavaAMOS callin/callout interface and Goovi
Defines the standard JavaAMOS driver.
To make a new version of JavaAmos
  • Compile the project with rebuild or make
  • Go to Wizards->Deployment Wizard in the main menubar
  • Deploy jar file in ../bin/javaamos.jar
