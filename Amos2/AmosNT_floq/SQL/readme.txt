1. Install Amos II in AmosNT/bin as usual by command 'install'.

2. To add SQLFront to the installed Amos II system give in this directory the command:
   compile

3. When compiled you can run the system with
    amos2

4. Regression test with
   lisp;
   (load "regress/master.lsp")


That's it! 
Keep it simple!
