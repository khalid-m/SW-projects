Script files for L=64 are in AmosNT/scsq/lr/scsq-plr/:

lwc.sh/run_cluster.sh starts the entire scsq-plr.
However, the checked-in version is configured for L=100.
Thus, the following needs to be done,
(1) set lrinputfiles(64)
(2) change dlrnomysepib in lr.osql, similar to /lr/experiment/lrsimple.osql

When running scsq-plr on a single node (e.g. for testing), the following lines
must be commented out. Otherwise, the scheduler is fooled.
     sp_basehostnum(1);
     sp_currenthostnum(0);

Cluster specific configuration is in
	$(AMOS_HOME)/scsq/config/spconfig-xxxx
In most cases, spconfig-linux.osql is enough.
