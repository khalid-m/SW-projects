COOLER VALIADATION

1. Install Python and Scientific Python

 Install 32-bits Python v2.7 from:
 http://www.python.org/download/ 
       or 
 http://user.it.uu.se/~udbl/software/python-2.7.2.msi

 Install 32-bits Numeric Python from:
 http://sourceforge.net/projects/numpy/
       or
 http://user.it.uu.se/~udbl/software/numpy-1.6.1-win32-superpack-python2.7.exe

 Install 32-bits Scientific Python from:
 http://sourceforge.net/projects/scipy/
       or
 http://user.it.uu.se/~udbl/software/scipy-0.13.0-win32-superpack-python2.7.exe


2. Go to directory: Vortex/Hagglunds/data
   
   unzip the file "COOLER.zip"
   make sure that all the csv file goes to: Vortex/Hagglunds/data/COOLER/ 

3. Go to the directory: Vortex/Hagglunds/

4. Regression test can be done by: 
   
   testCOOLER.cmd

5. To run individual queries, look into "HagglundsCOOLERDemo.osql"
