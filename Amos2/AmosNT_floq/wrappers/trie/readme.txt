To run SCSQ-trie:
1-Install Amos
2-create the executable by oppening and building project under SCSQ-trie\VC_prj
3-Install SCSQ-trie
4-run!

Content of the sub folders:

--------------lr-trie folder------------
HP trie (judy) based implementation of the Linear Road Benchmark


---------------SCSQ-trie-----------------
Visual C project extending Amos(Alisp) with B-trees, Naive tries and HP trie (Judy)

---------------JudyMexinmaDLL----------------
Dynamic extension of Amos to include Judy using MEXINMA
