Before running LR.cmd, depending on the experiments that you want to do, perform the following 'setup' actions:

1-Select the right visited.lsp version from src\visited.lsp_versions folder and copy it to src folder
2-rename the file you copied in above step to visited.lsp
3-Install LRB using install.cmd

Note that the maximum address space for a 32 bit application is 2GB of main memory.
The image size of Amos has to be adjusted so that both Amos image and external index can run;
too big image size leave not enough space for the index, and too small image size can’t provide space for other LRB functions in Amos.
The default image size of 1400000000 is suggested. Image size can be adjusted in loadhistory.osql
