This directory contains two regression tests for ODBC AMOS:

1. A basic test of the ODBC wrapper.
   To run it, start odbc-basic-test.bat

2. A more advanced test involving derived types, external types and tables in 
   an Access database.
   To run it:
   - start run.bat (starts 2 AMOS servers, one of them ODBC wrapper)
   - start client.bat
   
In order to run the tests:
1. Add a DSN named "ODBCTEST", and select the file idadb.mdb fom this directory
   as the the datasource.
2. Make sure that amos2.dmp was generated by with oamos.exe
   (by using "install odbc" in ..\..\bin)
   
The directory IDAGEN contains the Java application that creates and populates the
test database. It requires JDK 1.1.x and an Access ODBC driver.
