# Rewrite-rule catalogue

Every rewrite-rule registration in [AmosNT_floq/](AmosNT_floq/), generated by
[tools/gen_rewrite_rules.py](tools/gen_rewrite_rules.py). Do not edit by hand; rerun the script.
How TR and TBR rules work: [QUERY_COMPILER.md §6](QUERY_COMPILER.md#6-two-kinds-of-rewrite-rules)
and [OPTIMIZER.md §4](OPTIMIZER.md#4-rewrite-rules-in-practice).

| Kind | Registered with | Runs |
|---|---|---|
| **TR** | `(define-tr-rewriter 'fn 'test 'action)` | during each `rewrite` pass (`inferequals`), before cost-based optimization; one per function |
| **TBR** | `(add-rewriter fn bpat rewriter)` | inside the greedy loop (`rewrite-preds`), once bindings are known |
| **late TR** | `(define-late-tr-rewriter fn 'test 'action)` | TR rules applied only after view expansion (`call-late-tr-rewriters1`); installed by AQIT, [aqit/lsp/late-tr-rewrite.lsp](AmosNT_floq/aqit/lsp/late-tr-rewrite.lsp) |
| **index** | `(putprop '<type> 'index-rewriter 'fn)` | added as a TBR rewriter on each relation that gets an index of that type (`addindex0`) |
| **AmosQL** | `('<bpat>' foreign '<impl>' rewriter '<fn>')` in `create function … as multidirectional` | a TBR rewriter declared with the function; `rewriter 'x'` registers the Lisp function `rewrite-x` (`define-tbr`, [TBR.lsp:412](AmosNT_floq/lsp/TBR.lsp#L412)) |

**Image** = the file is loaded into the standard `amos2.dmp` (followed from `init.lsp`, plus the few
files outside `lsp/` that `init.lsp` loads). Other rows belong to extensions, wrappers or experiments
that load their own code. Several registrations sit inside a function body (e.g. `addindex0`,
`define-tbr`) and only run when that function is called. For a TBR rule, the rewriter's binding pattern uses `-` = bound and `+` =
free; AmosQL patterns use `b` = bound and `f` = free. Registrations built from variables show the
expression as written.
