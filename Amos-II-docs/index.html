Amos II
Wrappers


The extensible main memory database system sa.amos enables scalable processing of queries to data represented in many different forms, both regular databases, various file formats, and storage managers. The sa.amos system is maintained by Stream Analyze and is free for non-commercial use and can be downloaded from here.
