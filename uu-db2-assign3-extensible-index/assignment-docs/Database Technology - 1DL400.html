    Software

    The assignments will require to use the DBMSs MySQL and Amos II running on Windows. The software and databases will be stored on the USB stick we give you at the start of the course.

    Installation:
    1. Download the zip files xampp.zip and amos2.zip to your USB stick.
    2. Unzip xampp.zip the root directory of your stick. The directory named 'xampp' must be top level directory of the stick.
    3. Unzip amos2.zip to a new directory named 'amos2' on the stick. The directory named 'amos2' must be top level directory of the stick
    No more installation is required.

    Notice that unpacking the zip files (411 MB) to the stick may take more than 25 minutes, so prepare the USB stick before the assignment occasion so you don't waste time.
    MySQL
    Assignment 1 requires the relational DBMS MySQL.

    The manual for MySQL is here. To run MySQL go to the directory 'xampp' on the USB stick where you find the following command procedures to run MySQL:
    1. Click 'mysql_start' in folder 'xampp' to start the MySQL server.
    2. Click 'mysql_prompt' in folder 'xampp' to run the SQL top loop in MySQL (no password).
    3. Click 'mysql_stop' in folder 'xampp' to stop the MySQL server. Do not pull the stick without first ejecting it. Do not kill the MySQL server process from the task manager or by closing the server console window, as the database may then become corrupted.
    In order not to be mixed up with some other MySQL server running on the same computer, the client/server communication for the MySQL server on the stick is using port 4306 (the default MySQL port is 3306).

    The SQL scripts populating the database are in JohnsonSchema.sql, JohnsonData.sql, and extension.sql. Download these scripts to the 'xampp' directory on the USB stick. Then populate the database by giving the following command to the MySQL top loop:

    mysql> create database JohnsonBrothers;
    mysql> connect JohnsonBrothers;
    mysql> source JohnsonSchema.sql;
    mysql> source JohnsonData.sql;
    mysql> source extension.sql;

    At any point, if you would like to erase the whole JohnsonBrothers database issue the following command:

    mysql> drop database JohnsonBrothers;


    You can exit from mysql prompt by typing;

    mysql> quit;


    Once the above commands are run successfully the database is created on the USB stick in directory xampp/mysql/data/johnsonbrothers.
    Amos II
    Assignments 2 and 3 require Amos II.

    The manual for Amos II is here. To run Amos II go to the directory 'amos2/bin' on the stick and run 'amos2.exe'. You should first run and understand the examples here and then do the tutorial in tut.pdf.

    Registration

    The assignments should be solved in groups of 2-3 persons. It is your responsibility to form the groups. Please do not register groups until you are sure of all the members of the group. Assistants have the right not to correct the assignments that are submitted individually.

    Submitting

  • Solutions should be sent ONLY by email to the assistant. In attachment, it should contain the executable code (SQL for assignment 1, AmosQL for assignment 2, AmosQL and Java for assignment 3), and any additional logs and graphics in separate files.
  • For each assignment there is a deadline. We guarantee that assignments submitted before their respective deadline will be graded in a week from the deadline. Assignments that are turned in after deadline will be graded whenever we have time (possibly after the exam). There is a 'hard' deadline after which we will not accept new assignments.
  • If you fail on an assignment, you have to complete it and submit it again according to the assistants' comments. Failed assignments can be collected only from the correspondent assistant during his/her consultation time.
